Author - Steven Jones
Purpose - Create a version of the popular Tic-Tac-Toe in order to learn basics of syntax, arrays, and conditionals without being handed skeleton code.
It also gave me freedom to test different ideas and handle mapping lower dimension decisions onto higher dimensional fields and practice using dedicated functions. 
Note - There are known issues like duplicate code, unbounded recursion, etc. This is one of the first coding projects I did fully on my own as a learning tool outside of classes.
This should not be considered for evaluations and only as a comparison of where I was and where I am now.
